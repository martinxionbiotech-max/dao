# Content Guidelines

## Editorial workflow
Chinese/English sources → source verification → historical context → terminology
analysis → translation comparison → interpretation comparison → disagreement
detection → modern research → practitioner experience when relevant → independent
analysis → original English synthesis.

Every substantial article answers: what sources say; what historical evidence exists;
what scholars interpret differently; what the tradition says; what practitioners
report; what modern research shows; what remains uncertain; the editorial synthesis.

## Anti-hallucination (hard rules)
- Never invent books, papers, quotations, Chinese texts, events, teachers, lineages,
  interviews, practitioners, fieldwork, findings, citations, statistics or experiences.
- Never convert legend→history, belief→fact, community opinion→consensus,
  one experience→universal experience, AI interpretation→historical interpretation.
- Missing information: omit or write "Not reported." — never fabricate.

## Practitioner material ingestion
Raw community input (WeChat/Discord/forums/notes) is NOT an article. Pipeline:
clean → anonymize → extract → classify → structure → connect → edit → publish →
update knowledge graph. Decisions: KEEP AS NOTE / REPORT / MERGE INTO PATTERN /
CREATE PATTERN / QUESTION / UPDATE CONCEPT / RESEARCH TOPIC / EDITORIAL ARTICLE /
STORE INTERNAL / REJECT. Privacy: no real names, usernames, phones, emails, locations;
no direct quotes without permission; paraphrase + anonymize otherwise.

## Quality gate (before publication)
1. Genuinely useful? 2. Source identifiable? 3. Sufficiently original?
4. Evidence type clear? 5. Private info removed? 6. Unsupported claims removed?
7. Traditional claims separated from scientific? 8. Uncertainty preserved?
9. Connects to existing entities? 10. New knowledge value? 11. Answers a real question?
12. Deserves indexing? — else do not publish; store internally.

## Duplication control
Existing page covers the concept → update it. New experience fits a pattern → add to
pattern. New question belongs to a problem → update the problem page.
