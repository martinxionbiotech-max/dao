# Source Policy

## Source classes
- Primary texts: Daodejing, Zhuangzi, Qingjing Jing, Neiguan Jing, Huangting Jing...
  Quote with translation; cite edition/translation used.
- Historical scholarship: named authors, published works. No fabricated citations.
- Modern research: named study, method, population, findings, limitations, what it
  does NOT prove. Never overstate.
- Tradition/lineage: labelled TRADITIONAL / LINEAGE INTERPRETATION, not history.
- Practitioner reports: anonymized, labelled PRACTITIONER EXPERIENCE, never
  presented as scientific evidence.

## Chinese-language research
Chinese sources are investigated via web research and recorded in data/sources.json.
Unverifiable claims carry the UNCERTAIN class.

## Sourcing rule for AI overviews
Every page states evidence class in frontmatter and in-page tags; answer-first
summaries include uncertainty explicitly — this is what makes pages citable.
