# Dao — Chinese Contemplative Traditions Knowledge Base

English-language knowledge infrastructure connecting Chinese contemplative
traditions, classical texts, historical scholarship, modern research and
anonymized practitioner experience — with explicit evidence classification
and a structured knowledge graph.

## Develop
```bash
npm install
npm run dev
```

## Build
```bash
npm run build   # outputs dist/
```

## Structure
- `src/content/<collection>/` — markdown content (17 collections)
- `src/data/*.json` — structured datasets / knowledge graph
- `src/pages/` — routes
- `docs/` — architecture, schemas, guidelines
